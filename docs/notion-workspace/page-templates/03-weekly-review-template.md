## 4. Inbox triage (3 min)

Open Ideas Inbox → 📥 Raw inbox view.

For each item:
- **Move to Features** if it's a real product feature → set Status = Idea
- **Move to Tasks** if it's a discrete action item → set Status = Not started
- **Move to Marketing Content** if it's a post or content idea
- **Kill it** if it's not worth doing → set Stage = Killed (don't delete, the no-pattern is data)
- **Keep raw** if it needs more time to bake

Then check Bugs → 🔴 Open blockers. Any been open >7 days?
