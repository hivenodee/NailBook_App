## 💎 The vision (the why)

The single sentence:

> Most Black beauty pros take bookings via Instagram DM. It's broken. PoroBook is the editorial-luxury alternative built specifically for that audience.

The current incumbents are Square, GlossGenius, Vagaro, Acuity — none built for Black beauty pros, all generic-white-default by reflex. The brand register is wrong, the imagery is wrong, the voice is wrong. PoroBook closes that gap by treating the audience as the primary user, not an afterthought.

The win condition for V1 isn't user count — it's **the loop closing**: client books → pays deposit → arrives → completes appointment → leaves feedback → rebooks 6 weeks later. If 5 beta providers complete 5 of those loops, V1 has shipped.

## ✨ Brand quick-reference

**Voice:**
- Confident, never apologetic
- Short sentences
- Sentence case for UI labels
- No exclamation points (unless celebrating)
- No corporate filler ("seamless," "leverage," "empower")
- No em-dashes in production copy

**Visual:**
- Cream `#FBF8F3` + Rust `#C4732A` + Ink `#1A1614`
- Playfair Display (display) + DM Sans (body)
- Editorial photography of real Black women
- Sharp rectangles, minimal shadows, border-based card elevation
- 1 hero image per surface — never stack

**References:** Aesop · Pat McGrath · Mytopicals · Resy. **Not:** Material, generic SaaS, "girl boss" brands, neon beauty.

## 🚦 Decision rules (when you're stuck)

When considering whether to build / ship / decide something, run it through these:

1. **Does it help a real beta provider take a real booking?** If no, defer.
2. **Is it in V1 scope per the product spec?** If no, deflect to "V2 — see open questions."
3. **Does it match the editorial brand register?** If it feels SaaS-y, redo.
4. **Will it embarrass me in front of the first 5 providers?** If yes, fix before launch.
5. **Is it on the launch playbook?** If no, ask why it's there.

When in doubt: **do less, ship sooner, get real users on it**.
